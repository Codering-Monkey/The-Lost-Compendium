Welcome to the Lost World, a place much like our own yet so very different

The lost world is a custom D&D (Dungeons and Dragons) world that I have developed, It is similar to an alt-history, with the same geography but completly different history. This is the Lost compendium, a collection of all information regarding the lost world along with a few tools that I created to make playing the game easier
